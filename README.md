# Handwritten Character Recognition

A machine learning-based **Handwritten Character Recognition** project developed as part of the **CodeAlpha Internship**.

## 📌 Project Overview

This project focuses on recognizing handwritten characters from images using **image processing and machine learning techniques**.

The system takes a handwritten character image as input, preprocesses the image, extracts relevant features, and uses a trained machine learning model to recognize the character.

## 🔄 Workflow

```text
Handwritten Character Image
            ↓
    Image Preprocessing
            ↓
     Feature Extraction
            ↓
   Machine Learning Model
            ↓
     Character Prediction
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Fatima-yadwad/CodeAlpha_HandwrittenCharacterRecognition.git
```

Navigate to the project:

```bash
cd CodeAlpha_HandwrittenCharacterRecognition
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

Open the Jupyter Notebook available in the `notebooks` folder and execute the cells sequentially.

The notebook contains the workflow for:

1. Loading the handwritten character data
2. Preprocessing the images
3. Extracting features
4. Training the machine learning model
5. Testing the model
6. Recognizing handwritten characters
